# 🔥 Landing Page для модели

Красивый лендинг с видео фоном и кнопкой. Автоматически отправляет нужное гео на твою ссылку.

---

## Как это работает

Человек заходит на сайт → система определяет его страну → если страна из твоего списка → переходит на твою ссылку. Всё остальное гео можно отправить на другую ссылку или туда же.

---

## Шаг 1 — Скопируй репозиторий

1. Нажми зелёную кнопку **Use this template** вверху страницы
2. Нажми **Create a new repository**
3. Придумай название (например `my-landing`) → нажми **Create repository**

---

## Шаг 2 — Загрузи видео

Тебе нужна прямая ссылка на `.mp4` видео. Самый простой способ:

1. Зайди на [cloudinary.com](https://cloudinary.com) → зарегистрируйся бесплатно
2. Загрузи своё видео через **Media Library → Upload**
3. Кликни на видео → скопируй URL (должен заканчиваться на `.mp4`)

> Если видео в формате `.MOV` (iPhone) — сначала конвертируй:
> Открой Терминал на Маке и напиши:
> ```
> ffmpeg -i твоё_видео.MOV -vcodec h264 -acodec aac -movflags faststart video.mp4
> ```
> Если ffmpeg не установлен: `brew install ffmpeg`

---

## Шаг 3 — Задеплой на Railway

1. Зайди на [railway.app](https://railway.app) → войди через GitHub
2. Нажми **New Project** → **Deploy from GitHub repo**
3. Выбери свой репозиторий → нажми **Deploy Now**
4. Подожди 1-2 минуты пока задеплоится

---

## Шаг 4 — Заполни настройки

В Railway зайди в свой проект → нажми на сервис → вкладка **Variables** → **Raw Editor** → вставь и заполни:

```
SITE_NAME=Lily
SITE_SUBTITLE=Check my exclusive content ❤️
HERO_URL=https://ссылка-на-твоё-видео.mp4
CTA_TEXT=Exclusive content here
MAIN_LINK=https://t.me/+твоя_ссылка
FALLBACK_LINK=https://t.me/+твоя_ссылка
ALLOWED_GEO=US,GB,CA,AU,DE,FR,IT,NL,CH,AT,SE,NO,DK,FI,PT
GA_ID=
```

**Что каждая строка означает:**

| Строка | Что писать |
|--------|-----------|
| `SITE_NAME` | Имя которое будет на сайте |
| `SITE_SUBTITLE` | Маленький текст под именем (можно оставить пустым) |
| `HERO_URL` | Ссылка на видео или фото для фона |
| `CTA_TEXT` | Текст кнопки |
| `MAIN_LINK` | Куда идут платёжеспособные страны |
| `FALLBACK_LINK` | Куда идут все остальные (можно ту же ссылку) |
| `ALLOWED_GEO` | Список стран через запятую |
| `GA_ID` | Google Analytics (необязательно, можно оставить пустым) |

После заполнения нажми **Deploy** — сайт обновится автоматически.

---

## Шаг 5 — Проверь что работает

Открой в браузере:
```
https://твой-сайт.up.railway.app/check
```

Увидишь свою страну и `"allowed": true` или `false`.

---

## Шаг 6 — Свой домен (необязательно)

1. Купи домен на [namecheap.com](https://namecheap.com) (~$9/год)
2. Railway → Settings → Networking → **Custom Domain** → введи домен
3. Railway покажет две DNS записи
4. Namecheap → Advanced DNS → добавь обе записи
5. Жди 10-30 минут → домен заработает

## Частые вопросы

**Сайт выдаёт ошибку после деплоя?**
Подожди 2-3 минуты и обнови страницу.

**Видео не играет на сайте?**
Убедись что ссылка в `HERO_URL` заканчивается на `.mp4` и открывается в браузере напрямую.

**Хочу добавить второй сайт для другой модели?**
Railway → **+ Add** → выбери тот же репо → заполни другие Variables. Каждый сервис получит свой URL.

**Как добавить больше стран?**
В `ALLOWED_GEO` добавь коды через запятую. Примеры: `JP` Япония, `KR` Корея, `ES` Испания, `PT` Португалия.
